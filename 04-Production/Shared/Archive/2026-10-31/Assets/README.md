# Shared production assets

Reusable masters live here, grouped by asset name; create only the groups actually needed. Typical groups are ECCO, Well, Assembly, Effects and Branding.

Preserve supplied originals, record provenance/units/version and keep reusable master changes here. Individual shot animation belongs under `04-Production/Shots/`; standalone mechanism tests belong under `04-Production/Mechanisms/`.

This README establishes the destination; it does not assert that any model has been supplied or validated. Follow the [production workspace conventions](../../README.md), register actual assets through A02, and validate links before task closure.
