## How agents use this material

The [rolladice-scene-director skill](../00_Skill/rolladice-scene-director/SKILL.md) decides which documents to read, then emits the [Scene Direction Contract](07-SCENE_DIRECTION_CONTRACT_v0.2.md). The separate [blender-animation-reference skill](../00_Skill/blender-animation-reference/SKILL.md) prepares motion assets **after** a Blender animation exists.

- User quotations ≠ assistant interpretations ≠ accepted reference frames ≠ reviewed finished shots.
- Artistic preferences guide decisions but never override client/engineering constraints.
- Do not treat FutureDeluxe or Tendril as styles to imitate literally; synthesize independent principles into original work.
- Record real approvals with exact shot/version/date and add new director feedback to the evidence register before promoting proposed taste rules.

## Established and open taste

**Now evidenced:** quiet, elegant sans-serif editorial typography; emphasis on wording/composition; gentle fades or graceful motion; typography composed with imagery; either screen-space or spatial type by situation. Territory-style 3D/camera graphic integration is appreciated but optional. Read [08](08-TYPOGRAPHY_AND_GRAPHIC_INTEGRATION_v0.3.md) for evidence boundaries.

**Still undiscovered:** exact font family/typographic metrics and the technical motion-graphics design language (linework, data graphics, annotation density, transitions). MIT-required labeling and approved branding remain obligations.
