**Authority precedence:** MIT-approved geometry/engineering and contractual/client branding constraints → agreed narrative purpose → Rolladice's evidence-backed taste → individual shot decisions → execution convenience. A storyboard is a **proposal**, not a source of independently verified physics.

## Agent routes

- **Fact check or review a technical assertion:** Engineering Baseline → Decision Register → original source.
- **Design a new shot:** relevant V2 storyboard section → Engineering Baseline → MIT Production Identity → Rolladice Taste → Scene Direction Contract → scene-director skill.
- **Build or inspect a Blender scene:** approved shot direction and registered assets → Workflow → playblast → technical/creative review.
- **Prepare an existing Blender animation for a video model:** Workflow → blender-animation-reference skill; do not mistake it for the art-director.
- **Handle client feedback:** storyboard section-specific register for the original comment, then update the central Decision Register only for global blockers/approvals.

Read only the relevant documents for the task. Never load all 33 storyboard panels or all skill implementation scripts by default.
