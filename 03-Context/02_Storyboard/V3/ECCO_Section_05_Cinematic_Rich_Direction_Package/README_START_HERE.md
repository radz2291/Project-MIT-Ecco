# Section 05 — ENP3 Hydraulic Enhancement

## Start here

This package is a **cinematic-direction handoff** for Section 5 of the ECCO ENP3 film.
It is not the mechanical board and not the final Blender execution spec.

The purpose of this section is to show that ENP3 is not only a sensing tool. Its physical body also helps manage drilling-mud flow and hole cleaning.

## Section-level message

The audience should understand three things:
1. the tool body accelerates and guides upward mud flow,
2. the twisted hydraulic geometry actively agitates and redirects that flow,
3. the downstream body geometry helps manage the wake so the hydraulic stages work as one integrated system.

## Important caution

These images are cinematic composition references. They are not validated CFD/FEA plots.
If MIT later provides real FEA/CFD output, those data-driven flow patterns should take precedence during engineering polish.
