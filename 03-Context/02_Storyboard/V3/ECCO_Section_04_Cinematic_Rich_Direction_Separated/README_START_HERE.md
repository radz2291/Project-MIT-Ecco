# ECCO SECTION 04 — CINEMATIC DIRECTION / SEPARATED PACKAGE

**Read this first.** The user selected the annotated four-shot Option 2 composition. This package separates that exact image into four independent files, **one per film shot**, and provides rich agent instructions plus a copy/paste Padlet caption alongside each image.

- `S04_A_Entering_the_Cased_World/` — image, detailed direction, separate Padlet caption
- `S04_B_What_Lies_Behind_Steel/` — image, detailed direction, separate Padlet caption
- `S04_C_The_Hidden_Channel/` — image, detailed direction, separate Padlet caption
- `S04_D_The_Damage_Within/` — image, detailed direction, separate Padlet caption
- `DIRECTOR_SHOT_ARCHITECTURE_DETAILED.md` — the full 18-second film-level direction

## Usage

For your Padlet, create four shot posts, upload the corresponding image from each shot folder, and copy the corresponding `PADLET_CAPTION.md` into each post. Use the master Director document as the downstream AI agent's primary reference.
