# Proposed Agnostic Skills — Build Queue

**Status:** Draft skills for review and testing. A file in this folder is **not automatically installed** in ChatGPT/Codex, and does not replace active project skills.

Each proposal is portable across clients, media, and projects. It describes a reusable *method*, never a specific director's taste or a client's brand rules. Move a skill into the active skill routing only after its user acceptance and a real-use test.

## Boundaries

- **Proposal status:** These are candidate skills, not automatically enabled agents or production policy.
- **Knowledge ownership:** Use external, project-specific taste profiles and technical sources at runtime. Do not copy Rolladice or MIT preferences into the agnostic skill.
- **Overlap avoidance:** 01 discovers and records taste; 02 evaluates contextual choices; 03/04 specialize in production direction; 05 packages/validates execution. Skills 04–05 remain uncreated; each will be implemented in its own focused session.
- **Acceptance:** At minimum, validate the skill folder's format, exercise the workflow on realistic positive/negative/revision cases, and get the user's approval before promotion.

The [parent skills index](../README.md) lists **active** workflows separately.
