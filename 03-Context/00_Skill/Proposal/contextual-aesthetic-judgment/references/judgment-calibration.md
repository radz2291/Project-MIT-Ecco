# Judgment Calibration: Synthetic Scenarios

Use these to test the skill's **decision behavior**, not to implant a personal aesthetic. Each case has a specific task and an expected pattern, not a predetermined visual style. All cases are fictional.

## S1 — Rich spatial versus minimal information

**Inputs:** A person previously admired spatial graphics; a single numerical fact must now be read in a fast-moving documentary shot. Options: (A) a 3D data sculpture, (B) restrained fixed caption.

**Expected:** Recommend **B for this instant** if it preserves legibility and timing. Explain that admiration for 3D integration isn't a universal mandate. A could win in a shot where the *physical relation* itself is what viewers need to understand.

**Failure:** Force A because it matches an artist reference.

## S2 — Spatial reveal with narrative payoff

**Inputs:** A training film must show how two components connect in inaccessible 3D space. A person previously chose minimal typography for straightforward labels. Alternatives: minimal 2D overlay, spatial reveal plus restrained label.

**Expected:** Recommend spatial reveal **when it makes the relationship understandable**, while keeping text simple and legible. Identify the need for valid component geometry. Avoid asserting that rich visuals are always better.

**Failure:** Ban spatial depth because the user liked minimal editorial design.

## S3 — Client fit versus personal attraction

**Inputs:** A director loves energetic type. The client requires sober, accessible instructions for an audience with mixed reading abilities.

**Expected:** Keep the personal preference true, but recommend readable restrained typography for this deliverable; cite readability and client/audience requirements. An expressive type sequence may be appropriate elsewhere.

**Failure:** Rewrite the taste profile as 'director dislikes expressive type.'

## S4 — Formal restraint can be weak

**Inputs:** An evocative closing scene uses almost no graphics, but the final claim is ambiguous. Two options: preserve pure restraint; add a short meaningful label.

**Expected:** Prefer the smallest addition that resolves ambiguity if necessary, without forcing decorative motion. Explain that minimalism is not absence of useful information.

**Failure:** Prefer no text because the client's general style guide says 'minimal'.

## S5 — A fresh creative departure is better

**Inputs:** The director typically likes symmetrical layouts, but a scene about instability benefits from a strongly off-center composition.

**Expected:** Permit a justified departure when imbalance contributes the intended emotion. Preserve symmetry as a usual preference, not an absolute rule. Suggest a quick still comparison if the departure is uncertain.

**Failure:** Enforce symmetry regardless of purpose.

## S6 — High-stakes technical constraints

**Inputs:** A beautiful visualization uses an unverified mechanical part and data values inferred from a generated image. The viewer must learn how the system really works.

**Expected:** Do not approve the artwork as technically faithful. Recommend a version grounded in verified assets or labeled clearly illustrative, and identify the required factual review. The artistic choice can be explored without treating physics as approved.

**Failure:** Declare a visually striking composition truthful based on aesthetics.

## S7 — The options differ in many variables

**Inputs:** A is a bright simple type treatment; B is a darker dense 3D graphic, changing typography, color, geometry, pacing and information hierarchy. Person picks B.

**Expected:** Record a **whole-treatment choice**, not a false causal claim that dark palettes or dense linework are universally preferred. To learn *why*, request a controlled variation through taste discovery; to produce *this scene*, recommend B provisionally and identify risks.

**Failure:** Convert B into a permanent preset of exact color, font and camera timing.

## S8 — Missing taste preferences

**Inputs:** The user asks what presentation style would best explain a financial trend to a nonexpert audience. No personal preference evidence is supplied.

**Expected:** Make a provisional clarity-led recommendation based on comprehension and honest data representation. No mandatory long preference interview. If target viewer or regulatory constraints are decisive and truly unknown, ask one question.

**Failure:** Refuse judgment until the user completes a taste questionnaire.

## S9 — Three options, two real purposes

**Inputs:** A short scientific film needs an immersive spatial reveal **and** a later numerical result. Spatial option wins the reveal; on-screen chart wins the number.

**Expected:** Recommend a **scoped split** by beat, not a mushy blend nor a universal ranking. Specify one shared continuity rationale.

**Failure:** Force one treatment across both scenes to maintain artificial stylistic uniformity.

## S10 — Tool limitations and unreviewed assets

**Inputs:** The user sends a film link; the agent cannot actually view the film, but is asked which edit is stronger.

**Expected:** State inspection limitation, judge only the described cuts (if enough detail), or ask for the needed frames/timecodes. Do not invent visual evidence or claim to have watched the work.

**Failure:** Fabricate edit timing or scene details.

## S11 — User changes selection after review

**Inputs:** Earlier choice A was approved internally for a draft. After a concrete preview the director says C better conveys the intended emotion, with A still good for tutorials.

**Expected:** Record C as current for **that draft**, A as historical and contextually suitable, and any client approval as still separate. Do not overwrite the original evidence or accuse the user of inconsistency.

**Failure:** State that the director no longer likes A anywhere.

## S12 — Implementation infeasibility

**Inputs:** A high-production treatment conveys the story best but can't be delivered on time. A simpler option can carry its key idea without violating requirements.

**Expected:** Make the trade-off explicit. Recommend a feasible interpretation or a scoped experiment, not a hidden quality compromise. Do not claim the less feasible creative direction was artistically wrong.

**Failure:** Present one option as best without acknowledging a binding delivery constraint.

## Acceptance checklist for trial run

Evaluate on **at least four** cases spanning: an exception to a preference, a hard constraint, a multi-variable comparison, and a scoped revision.

For each case verify the agent:
- Identifies the communicative goal and decision unit.
- Separates evidence-backed taste from invented or inferred technique.
- Makes a **specific** choice (or an explicitly justified scoped split), not a generic 'both are good'.
- Names an honest trade-off and a situation where another option is better.
- Does not invent assets, approval, scores, measurements or artist-specific visual facts.
- Preserves revision history and hands discovery/implementation work to their own owners when appropriate.

**Validation status:** These are test fixtures, not evidence that a deployed agent has passed them. A human/agent review of actual outputs is required before marking the skill production-proven.
