# Agent Skills — Task Router

This folder contains reusable workflow instructions and related assets, not the authoritative source of client engineering facts or Rolladice creative taste.

| Skill | Use it for | Does not own |
|---|---|---|
| [rolladice-scene-director](rolladice-scene-director/SKILL.md) | Making creative scene, camera, lighting and previs decisions **before** production; uses Rolladice taste docs | MIT approval, verified CAD, finished Blender animation |
| [blender-animation-reference](blender-animation-reference/SKILL.md) | Inspecting and exporting **existing** Blender animation to motion-reference assets and AI-model handoff | Deciding cinematic taste from scratch |
| [mechanism-visual-direction-loop](mechanism-visual-direction-loop/SKILL.md) | Reviewing real visual mechanisms; diagnosing cause-and-response failures; directing bounded iterations with an execution agent | Engineering certification, universal style presets, full motion construction, human approvals |

## Reusable creative intelligence toolkit

[Creative Intelligence Toolkit](creative-intelligence-toolkit/README.md) groups five reusable methods: [Discover Creative Taste](creative-intelligence-toolkit/discover-creative-taste/SKILL.md); [Contextual Aesthetic Judgment](creative-intelligence-toolkit/contextual-aesthetic-judgment/SKILL.md); [Spatial Storytelling & Camera Choreography](creative-intelligence-toolkit/spatial-storytelling-camera-choreography/SKILL.md); [Information-to-Visual Storytelling](creative-intelligence-toolkit/information-to-visual-storytelling/SKILL.md); [Creative Knowledge-to-Execution Engineering](creative-intelligence-toolkit/creative-knowledge-to-execution-engineering/SKILL.md). All five v0.1 packages are written and structurally checked; they are **not automatically installed or production-validated**. Use the appropriate skill independently or together as needed; the active project-specific skills above remain unchanged.
