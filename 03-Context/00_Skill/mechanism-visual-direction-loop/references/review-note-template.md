# Mechanism Visual Review — One-Screen Template

Use in the *existing* ticket, review thread, or scene contract; never create a duplicate approval register.

- **Decision unit:** [one interaction/beat and intended viewer inference]
- **Actual candidate:** [file/link/version, frame or time range, medium, what was inspected]
- **Authority and uncertainty:** [verified facts/data vs illustrative effects; source and open review]
- **Previously accepted:** [exact visual/state components and reviewer where known]
- **Current reading:** "The viewer currently sees ___ instead of ___."
- **Diagnosis:** [one high-leverage perceptual issue + *hypothesized* cause; separate observed symptom from uninspected implementation]
- **PRESERVE:** [locked camera/object/approved decisions]
- **CHANGE:** [one bounded visual/behavioral correction]
- **FREE:** [implementation choices left to agent]
- **AVOID:** [false mechanism, unsupported data, rejected visual problems]
- **Next proof:** [one exact still/short preview of trigger → response, acceptance question]
- **Status:** [proposed / candidate / visually approved at named scope / technical review pending / superseded]
- **Next owner:** [director chooses, executor builds, domain expert verifies, etc.]

## A good focused note

**Current reading:** "A small glowing dot appears on the surface while the moving front is still separated from it, so contact does not read."

**PRESERVE:** current approved camera, real object positions, existing thin membrane material.

**CHANGE:** align visible leading wave to actual evaluated surface intersection and drive a localized response from that shared contact position. Allow the response to reveal adjacent surface structure rather than increase a single pixel's brightness.

**FREE:** raycast/geometry-node/shader implementation, exact mask controls, optimization after geometry inspection.

**Next proof:** one peak-contact still plus a short approach/contact/fade clip. Pass when viewer can recognize what triggered the response; inspect motion before claiming event timing works.

**Truth note:** if the pattern metaphorically visualizes acquisition, it is not a literal field measurement.

## A poor focused note

"Make it more futuristic, turn up the blue, add three glows, change the camera and regenerate everything."

**Why it fails:** no causal diagnosis; unbounded changes obscure which adjustment matters and can invalidate accepted work.
