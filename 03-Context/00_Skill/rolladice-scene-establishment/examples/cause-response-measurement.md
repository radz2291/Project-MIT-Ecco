# Example — Cause, Response and Recorded History

**Origin:** transferable lesson from the supplied ECCO Section 2 collaboration. Exact sensor behavior and timings must come from the active project's sources.

## The scene in ordinary language

A signal reaches a wall. A response returns. The instrument keeps a result, and the viewer sees that result join earlier measurements.

## Separate the three chains

**Physical chain:** send, encounter, return. Verify what the instrument actually does.

**Information chain:** recorded signal, any derived value, stored sample or reconstructed result. A visible waveform or distance marker represents information, not another physical object.

**Display chain:** temporary contact cue, confirmed result, a settled mark, accumulated history. Brightness and organic growth belong to presentation unless the source says otherwise.

## Establish one effect language

Use a consistent base element for current and historical results. Let age change brightness or connection state instead of changing graphic species. A marked wall position stays attached to that wall, not to the rotating tool or camera.

A center-out patch reveal can be a useful display treatment. It must not imply that one pulse acquires an entire circumference. Distinguish already available neighboring data, new samples and interpolation when that distinction affects the claim.

## Prove only the uncertain part

First test one complete send-contact-return-record event from a stable view. Then reveal pre-existing history while a small active event continues. Do not simulate every old sample merely to display its accumulated result.

If the effect reads poorly, compare a few genuinely different visual mechanisms. Do not offer five variations of the same glow. Preserve the camera, source position, wall and timing in a controlled comparison.

## A useful revision message

"The signal and return work. The new mark looks different from the old history, so it feels like a separate effect. Keep the camera and pulse. Make the fresh mark the bright, newly added version of the same element used in the history, then show one complete cycle."

## Transfer rule

This method also applies to a robot detecting damage, a sensor dashboard recording an event, or a medical instrument presenting a signal. The method transfers; the physical timings, safety claims, palette and instrument capabilities do not.
