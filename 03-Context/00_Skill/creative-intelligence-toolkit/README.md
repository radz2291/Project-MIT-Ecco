# Creative Intelligence Toolkit — Five Reusable Skills

A coherent group of **five project-agnostic creative skills**, carrying work from personal taste discovery through artistic judgment and direction to verifiable agent handoff.

**Package state:** Five v0.1 skill packages are authored and structurally checked. They are collected here as one toolkit, **not automatically installed or production-validated**. Each skill works independently; use only what the task needs. Real-use/cross-skill tests and optional promotion remain separate decisions.

## Skill collection

| Order | Skill | Job |
|---|---|---|
| **01** | [Discover Creative Taste](discover-creative-taste/SKILL.md) | Elicit and preserve evidence-backed creative preferences, including context and revisions |
| **02** | [Contextual Aesthetic Judgment](contextual-aesthetic-judgment/SKILL.md) | Choose a creative treatment for the actual goal, constraints and person, with justified exceptions |
| **03** | [Spatial Storytelling & Camera Choreography](spatial-storytelling-camera-choreography/SKILL.md) | Design purposeful images, visual arrivals, camera/subject motion and temporal continuity |
| **04** | [Information-to-Visual Storytelling](information-to-visual-storytelling/SKILL.md) | Turn concepts, mechanisms and data into truthful, understandable visual narratives |
| **05** | [Creative Knowledge-to-Execution Engineering](creative-knowledge-to-execution-engineering/SKILL.md) | Convert intent and authoritative sources into bounded tasks, inspected artifacts and verifiable evidence |

## How to use the group

**Discover → Decide → Direct space and/or information → Execute and verify.** This is a helpful sequence, **not mandatory orchestration**. Invoke one skill for a narrow problem; combine them when the job actually crosses boundaries.

- **Taste is not a universal preset.** Skill 01 captures what a person directly likes; Skill 02 judges how those preferences apply to a particular situation.
- **The viewer experience is the objective.** Skill 03 directs space and cinematic timing. Skill 04 directs meaning, data representation and the lifecycle of information. Neither owns the other's details.
- **A document is not a proof.** Skill 05 records authoritative sources, implementation freedom, artifacts, actual checks and unresolved approvals.
- **Client/project truth lives outside this toolkit.** Load relevant facts, brand rules, source assets and decisions from the current project. Do not transplant MIT or Rolladice preferences into unrelated projects.
- **Draft status is preserved.** Packaging is not a claim that these skills have passed live behavioral tests or have been installed into an agent runtime.

## Structure and maintenance

Each skill has its own `SKILL.md`, optional `references/` and `assets/`, and `agents/openai.yaml`. Supporting references are loaded on demand. No duplicated project-specific knowledge or separate global execution contract is required.
